Getting Started
  1. In the same room? Tap BLE (top-right) — works on Chrome/Edge, no internet needed.
  2. From anywhere (home/office)? Open Settings below, enter your HiveMQ host, username, password & device id, and tick Auto-connect so it links up every time you open the page.
  3. No broker yet? Create a free one at HiveMQ Cloud → Serverless → add an access user, then paste those details in Settings.
  4. Prefer dark? Use the 🌙 / ☀ button (top-right) — the app opens in light mode by default.
